# Automatica.Core Drivers

Here is a list of all built-in available drivers.

* [Automatica.Remote](./automatica.driver.automatica.remote)
    * Connect to a Automatica.Core Server
* [Constants](./automatica.driver.constants)
* [BMW CarData](./automatica.driver.bmwcardata)
    * BMW / MINI cars (CarData, read only)
* [BYD](./automatica.driver.byd)
    * BYD cars (cloud)
* [Dreame](./automatica.driver.dreame)
    * Dreame robot vacuums (Dreamehome cloud)
* [EnOcean](./automatica.driver.enocean)
* [FroniusSymo](./automatica.driver.froniussymo)
* [Gardena smart system](./automatica.driver.gardena)
    * Gardena valves, mowers, sockets, sensors (cloud)
* [Home Connect](./automatica.driver.homeconnect)
    * Bosch / Siemens / Neff / Gaggenau appliances (cloud)
* [Apple HomeKit](./automatica.driver.homekit)
* [HTTP](./automatica.driver.http)
    * Virtual HTTP inputs and outputs: read values from URLs, send HTTP commands
* [Hue Bridge Simulator](./automatica.driver.huebridgesimulator)
* [Husqvarna Automower](./automatica.driver.automower)
    * Automower robot mowers (Automower Connect API)
* [Ikea Tradfri](./automatica.driver.ikeatradfri)
* [KNX](./automatica.driver.knx)
* [Loxone Miniserver](./automatica.driver.loxone.miniserver)
* [MachineFlags](./automatica.driver.machineflags)
* [Mammotion](./automatica.driver.mammotion)
    * Mammotion Luba / Yuka robot mowers (cloud)
* [Miele](./automatica.driver.miele)
    * Miele@home appliances (cloud)
* [Network presence](./automatica.driver.networkpresence)
    * Who is at home, from the phones on the network
* [MBus](./automatica.driver.mbus)
* [ModBus](./automatica.driver.modbus)
* [OpenWeatherMap](./automatica.driver.openweathermap.driver)
* [Segway Navimow](./automatica.driver.navimow)
    * Navimow robot mowers (cloud)
* [Spot price](./automatica.driver.spotprice)
    * Day-ahead electricity prices (aWATTar, ENTSO-E) and cheapest-hours outputs
* [Tesla Powerwall](./automatica.driver.powerwall)
    * Tesla Powerwall 2 / Powerwall+ (local gateway API)
* [Tesla](./automatica.driver.tesla)
    * Tesla cars (Fleet API)
* [Times](./automatica.driver.times)
* [WakeOnLan](./automatica.driver.wakeonlan)
* [ZWave](./automatica.driver.zwave)
